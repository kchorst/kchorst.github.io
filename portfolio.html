How I Work

Stack and process

Local AI Development

16GB RAM, no-GPU laptop running llama-server with Qwen 2.5 Coder 7B. Connected to Continue in VS Code. Local 7B handles mechanical coding; Claude (browser) handles planning and architecture. Tested LAN and Tailscale connections for mobile-to-llama-server workflows.

Prompt Engineering

I think of prompts as specs, not requests. I use XML-tagged context blocks, explicit negative examples, and tiered outputs (e.g. two-tier distillation models). Most of my extension features start as a written spec before a line of code.

Chrome Extension Architecture

All recent extensions use Manifest V3 with chrome.storage.local, service workers, and where applicable, side panels. I've navigated the MV3 migration constraints around content scripts, CORS, and background persistence.

Curriculum Design

Designed a full vocational tech course for 8 high school students around gap/fill discovery pedagogy — no instructions, only objects and problems. Tracks: web server, LLM, music production, IoT. Capstone: video deliverable. LLM access was earned, not given.
