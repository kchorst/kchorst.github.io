How I work

Local AI Consulting

I help privacy-sensitive small businesses — attorneys, therapists, accountants, financial advisors — deploy local LLM systems that keep their data off the cloud entirely. Based in the Tri-Cities / Eastern WA market. Referrals welcome from local IT freelancers.

Local AI Development

16GB RAM, no-GPU laptop running llama-server with Qwen 2.5 Coder 7B. Connected to Continue in VS Code. Local 7B handles mechanical coding tasks; Claude (browser) handles planning and architecture. Tested LAN and Tailscale for mobile-to-llama-server workflows.

Prompt Engineering

I treat prompts as specs, not requests — XML-tagged context blocks, explicit negative examples, tiered outputs. Most of my extension features start as a written spec before a line of code is written.

Chrome Extension Architecture

All recent extensions use Manifest V3 with chrome.storage.local, service workers, and side panels where applicable. I've navigated MV3 constraints around content scripts, CORS, and background persistence.

Vocational AI Curriculum

Designed a full vocational tech course for 8 high school students around gap/fill discovery pedagogy — no instructions, only objects and problems. Tracks: web server, LLM, music production, IoT. LLM access was earned, not given.
